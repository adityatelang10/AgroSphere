# AgroSphere landing-page photography

These photographs are illustrative editorial visuals. They are not photographs
of AgroSphere users, live marketplace listings, an actual diagnostic input, or
proof of certification or origin. The tomato gallery combines independent stock
photographs; it does not represent different photographs of one real listing.

All photographs were downloaded from Pexels and optimized locally as WebP.
Hero variants use the same photograph at different resolutions. No runtime
image service or API key is required.

## Original project visuals

The landing-page layouts, leaf mark, evidence connections, system diagram,
irrigation rings and crop-passport illustration were created for AgroSphere.
The passport's scan symbol is decorative and does not encode a URL.

The existing DM Sans / Sora font pairing is reused. No imagery, copy, animations,
logo or layout was copied from Les Animals. Its site was studied only as a
reference for editorial hierarchy, restrained navigation and visual pacing.
